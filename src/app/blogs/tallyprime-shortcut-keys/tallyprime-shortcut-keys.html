Quick Answer

Which TallyPrime shortcut keys should accountants learn first?

Start with F2 to change the date, Alt+F2 to change the period, F4 for Contra, F5 for Payment, F6 for Receipt, F7 for Journal, F8 for Sales, F9 for Purchase, Alt+G to open Go To and Esc to return to the previous screen.

Shortcut behavior can depend on the active screen, configured voucher types and TallyPrime release. Verify context-sensitive shortcuts in your installed version.
01 / GETTING STARTED

Introduction to TallyPrime Shortcut Keys

If you work in accounting, entering transactions, managing ledgers, preparing reports and checking financial records can take up a significant amount of time. Learning the right TallyPrime shortcut keys can help you navigate the software more efficiently and reduce unnecessary mouse clicks.

TallyPrime provides keyboard shortcuts for navigating screens, entering vouchers, selecting dates, viewing reports and performing other accounting tasks. These shortcuts are useful for accountants, accounts executives, business owners and students learning computerized accounting.

This guide covers 50 shortcut references, organized by category, with simple explanations of when to use them. Whether you are a beginner or an experienced accountant, keep the list handy as a quick reference while working in TallyPrime.

Learn the shortcuts in context. A shortcut is most useful when you understand the task and verify the accounting entry it helps you create.
02 / UNDERSTAND THE BASICS

What Are TallyPrime Shortcut Keys?

TallyPrime shortcut keys are keyboard combinations or individual keys that help users access functions, navigate screens and perform tasks without relying entirely on a mouse.

Navigate faster

Access supported screens, menus and reports without repeatedly moving through menus.

Enter vouchers

Start common voucher workflows for payments, receipts, sales and purchases.

Review periods

Change the date or reporting period in screens where those functions are available.

Review reports

Open supported reports and drill down into displayed items where available.

Example

F2 is commonly used to change the date, while Alt+F2 changes the period in relevant TallyPrime screens.
