What You Will Learn

Build a strong foundation in computer networking by understanding network concepts, communication methods, network types, topologies, protocols, and real-world networking applications. Learn how computers, devices, and network infrastructure communicate with each other in modern IT environments.
Understand LAN, WAN, MAN, WLAN, PAN, and enterprise networks. Learn different physical and logical network topologies including bus, star, ring, mesh, and hybrid architectures, and understand how network design impacts performance, reliability, and scalability.
Learn the functions of essential networking devices including hubs, switches, routers, bridges, repeaters, access points, modems, firewalls, and network interface cards. Understand how these devices work together to build reliable network infrastructure.
Master the seven layers of the OSI model and understand the responsibilities of each layer. Learn protocols, addressing, encapsulation, data transmission, and how the OSI model is used to analyze and troubleshoot network communication problems.
Understand the TCP/IP model and its relationship with the OSI model. Learn important networking protocols including TCP, UDP, IP, ARP, ICMP, DNS, DHCP, HTTP, HTTPS, FTP, and SSH, and understand how these protocols support modern network communication.
Learn Ethernet networking fundamentals, MAC addresses, frame structure, data transmission, and ARP operations. Understand how devices identify each other on local networks and how Ethernet-based communication works across LAN environments.
Develop basic network troubleshooting skills by understanding connectivity testing, packet flow, common network errors, IP conflicts, cable and interface issues, and basic diagnostic commands. Learn how to identify and isolate common communication problems.
Apply your networking fundamentals by designing and configuring a small network environment. Create a network topology, connect devices, analyze communication using the OSI and TCP/IP models, configure basic connectivity, test network communication, and troubleshoot common networking issues.

Build a strong foundation in IPv4 addressing by understanding network addresses, host addresses, subnet masks, default gateways, public and private IP addresses, address classes, and how IP addressing enables communication between devices across computer networks.
Learn binary and decimal number systems used in IP networking. Practice converting IPv4 addresses between binary and decimal formats and understand how subnet masks, network bits, and host bits are represented at the binary level.
Master IPv4 subnetting by learning how to divide networks into smaller logical segments. Understand subnet masks, network IDs, broadcast addresses, usable host ranges, subnet calculations, and practical subnetting techniques for efficient network planning.
Learn Variable Length Subnet Masking (VLSM) and Classless Inter-Domain Routing (CIDR) for flexible and efficient IP address allocation. Design different subnet sizes according to network requirements and reduce unnecessary IP address usage.
Understand IPv6 addressing and the transition from IPv4 to IPv6. Learn IPv6 address formats, address types, prefix notation, interface identifiers, link-local addresses, global unicast addressing, and basic IPv6 configuration concepts.
Learn practical IPv6 subnet planning and address allocation. Understand IPv6 prefixes, subnet identifiers, hierarchical addressing, and how to design scalable IPv6 networks for organizations and enterprise infrastructure.
Configure and troubleshoot IPv4 and IPv6 connectivity using practical networking commands and diagnostic techniques. Learn to identify incorrect addressing, subnet mask issues, gateway problems, duplicate IP addresses, and connectivity failures.
Apply IPv4, IPv6, subnetting, VLSM, and CIDR concepts to a real-world network design project. Create an IP addressing plan, allocate subnets for departments, configure device addresses, test connectivity, and troubleshoot addressing issues across the complete network.

Learn the fundamentals of Ethernet networking and understand how devices communicate across local area networks. Explore Ethernet frames, MAC addressing, collision domains, broadcast domains, speed, duplex, and common Ethernet standards used in modern networks.
Understand the role of Layer 2 switches in network communication. Learn switch components, MAC address tables, frame forwarding, flooding, filtering, basic Cisco switch configuration, interface management, and essential switch verification commands.
Learn how switches learn and maintain MAC address tables. Understand unicast, broadcast, and unknown unicast traffic, frame forwarding, address-table entries, and switching behavior through practical networking exercises.
Learn Virtual Local Area Networks (VLANs) and understand how logical network segmentation improves performance, security, and manageability. Create VLANs, assign switch ports, configure VLAN membership, and verify VLAN connectivity in Cisco switching environments.
Understand trunk links and how multiple VLANs communicate across interconnected switches. Learn 802.1Q tagging, access ports, trunk ports, native VLAN concepts, VLAN propagation, and practical trunk configuration and verification.
Learn how multiple switches are connected in enterprise networks and how VLAN information is managed across switching environments. Configure interconnected switches, verify VLAN databases, troubleshoot trunk links, and maintain reliable Layer 2 connectivity.
Understand the purpose of Spanning Tree Protocol (STP) in preventing Layer 2 network loops. Learn root bridge selection, port roles, port states, path costs, and basic STP verification and troubleshooting in switched networks.
Apply Ethernet, switching, VLAN, trunking, and STP concepts by designing and configuring a multi-switch network. Create VLANs, assign ports, configure trunk links, verify inter-switch communication, implement basic Layer 2 redundancy, and troubleshoot common switching issues in a practical Cisco networking project.

Understand the fundamentals of IP routing and how routers forward packets between different networks. Learn routing tables, next-hop addresses, connected routes, routing decisions, and the role of routers in enterprise network communication.
Learn basic Cisco router configuration using the Cisco IOS command line. Configure interfaces, hostnames, passwords, IP addresses, descriptions, default gateways, and verify router connectivity using essential IOS commands.
Master static routing for connecting multiple networks. Learn how to configure static routes, default routes, floating static routes, route verification, administrative distance, and troubleshooting incorrect routing configurations.
Understand why devices in different VLANs require Layer 3 routing for communication. Learn the concepts of inter-VLAN communication, Layer 2 and Layer 3 boundaries, gateway configuration, and routing traffic between segmented networks.
Configure inter-VLAN routing using the Router-on-a-Stick architecture. Learn 802.1Q encapsulation, router subinterfaces, VLAN gateways, trunk configuration, connectivity testing, and troubleshooting communication between multiple VLANs.
Learn how multilayer switches perform routing between VLANs using switched virtual interfaces (SVIs). Configure VLAN interfaces, IP routing, default gateways, and Layer 3 switching for faster and scalable enterprise networks.
Develop practical troubleshooting skills for routing and inter-VLAN connectivity. Learn to identify incorrect IP addressing, missing routes, trunk configuration issues, subinterface problems, gateway errors, and routing table inconsistencies using Cisco verification commands.
Apply routing and inter-VLAN concepts by designing and configuring a multi-department enterprise network. Create VLANs, configure trunks, implement Router-on-a-Stick or Layer 3 switching, configure static and default routes, verify end-to-end connectivity, and troubleshoot network communication issues.

Understand the fundamentals of dynamic routing and how routers automatically learn and maintain network routes. Learn the advantages of dynamic routing, routing protocol concepts, route selection, convergence, and the role of routing protocols in scalable networks.
Learn the fundamentals of routing protocols, including distance-vector and link-state concepts. Understand routing metrics, administrative distance, convergence, route advertisement, and how routers select the best available path.
Learn Open Shortest Path First (OSPF), a widely used link-state routing protocol. Understand OSPF operation, router IDs, link-state advertisements, neighbor relationships, areas, and shortest-path calculation.
Configure single-area OSPF on Cisco routers using the Cisco IOS command line. Learn network statements, wildcard masks, router IDs, passive interfaces, OSPF neighbor formation, route advertisement, and verification commands.
Understand how OSPF calculates the best path using cost and interface characteristics. Learn route selection, reference bandwidth, OSPF database information, alternative paths, and optimizing routing decisions in enterprise networks.
Learn how OSPF can be designed for larger networks using areas and hierarchical architecture. Understand area concepts, backbone area, route summarization basics, and design considerations for scalable enterprise routing environments.
Develop practical OSPF troubleshooting skills by identifying neighbor formation issues, incorrect network statements, wildcard mask errors, passive interface problems, routing table issues, and connectivity failures using Cisco IOS verification commands.
Apply dynamic routing and OSPF concepts by designing and configuring a multi-router enterprise network. Implement OSPF, establish neighbor relationships, verify route propagation, test failover and connectivity, troubleshoot routing issues, and document the complete network design.

Understand Dynamic Host Configuration Protocol (DHCP) and how network devices automatically receive IP configuration. Learn DHCP server concepts, address pools, default gateways, DNS settings, lease management, and basic DHCP configuration and troubleshooting.
Learn the fundamentals of Domain Name System (DNS) and how hostnames are translated into IP addresses. Understand DNS records, name resolution, recursive and authoritative queries, DNS troubleshooting, and the role of DNS in enterprise network communication.
Understand Network Address Translation (NAT) and Port Address Translation (PAT). Learn static NAT, dynamic NAT, overload configuration, inside and outside interfaces, address translation tables, and practical configuration and troubleshooting of NAT in Cisco networks.
Learn wireless networking concepts including WLAN architecture, wireless standards, access points, SSIDs, channels, radio frequencies, wireless connectivity, roaming, and basic wireless network configuration for enterprise environments.
Understand wireless security principles and secure access methods. Learn authentication concepts, encryption, secure SSID configuration, access control, guest networks, wireless threats, and best practices for protecting enterprise WLAN environments.
Learn how Access Control Lists control traffic within a network. Understand standard and extended ACLs, access control rules, wildcard masks, placement of ACLs, filtering traffic, and practical Cisco ACL configuration and verification.
Build a foundation in network security by understanding common network threats, device hardening, secure administrative access, password protection, SSH, segmentation, security policies, and practical techniques for protecting network infrastructure.
Apply DHCP, DNS, NAT, wireless networking, ACLs, and security concepts by designing and configuring a practical enterprise network. Configure network services, secure wireless access, implement traffic filtering, verify connectivity, and troubleshoot common service and security issues.

Learn the fundamentals of Cisco IOS and understand how network administrators configure and manage Cisco routers and switches. Explore user EXEC, privileged EXEC, global configuration, interface configuration, and essential Cisco IOS command-line operations.
Configure Cisco devices using practical command-line exercises. Learn hostname configuration, passwords, banners, interface IP addresses, descriptions, device identification, configuration modes, and essential verification commands.
Learn secure methods for managing Cisco networking devices. Configure console access, privileged access, local user authentication, SSH remote management, password protection, login controls, and basic device hardening practices.
Learn how to manage Cisco device configuration files and protect network configurations. Understand running and startup configurations, configuration saving, backup and restoration procedures, device recovery, and maintaining reliable network configurations.
Develop practical skills for monitoring Cisco devices using show and diagnostic commands. Learn how to check interfaces, routing tables, VLANs, MAC address tables, device status, CPU and memory information, and network connectivity.
Learn a systematic approach to identifying and resolving network problems. Understand problem isolation, connectivity testing, interface diagnostics, IP configuration verification, routing checks, VLAN troubleshooting, and resolving common Layer 1, Layer 2, and Layer 3 issues.
Use practical diagnostic tools and commands to troubleshoot network failures. Learn ping, traceroute, IP configuration commands, interface diagnostics, ARP inspection, MAC table analysis, routing verification, and structured troubleshooting techniques for Cisco environments.
Apply Cisco device management and troubleshooting skills to a practical enterprise network. Configure routers and switches, secure device access, back up configurations, monitor network devices, identify connectivity problems, troubleshoot routing and switching issues, and restore network services using a structured troubleshooting methodology.

Understand the fundamentals of enterprise network architecture and learn how organizations design scalable, reliable, and secure network infrastructures. Explore hierarchical network design, LAN and WAN connectivity, core, distribution, and access layers, and enterprise network planning.
Learn the fundamentals of LAN and WAN technologies used to connect users, branches, data centers, and remote locations. Understand Ethernet-based LANs, WAN connectivity concepts, leased connections, and network communication across geographically distributed environments.
Understand network redundancy and high-availability concepts used to reduce downtime. Learn redundant links, gateway redundancy concepts, failover mechanisms, resilient network design, and best practices for building reliable enterprise infrastructure.
Learn how multiple physical links can be combined into a logical connection using EtherChannel. Understand link aggregation concepts, load distribution, redundancy, configuration requirements, verification commands, and practical EtherChannel configuration on Cisco switches.
Design scalable VLAN-based enterprise networks for departments, users, services, and different security zones. Learn network segmentation, VLAN planning, trunking strategies, IP addressing integration, and logical network organization for improved performance and security.
Learn how enterprise branches and remote offices connect to centralized network infrastructure. Understand WAN design concepts, branch connectivity, routing between locations, remote network communication, and practical enterprise branch network scenarios.
Learn how to plan, document, and present enterprise network infrastructure. Create logical and physical network diagrams, IP addressing plans, VLAN documentation, device inventories, connectivity maps, and network implementation plans following professional practices.

Create a professional network diagram, configure Cisco devices, test connectivity, and troubleshoot the final enterprise deployment.

Build a strong foundation in network security by understanding common threats, vulnerabilities, attack methods, security principles, and the importance of protecting network infrastructure. Learn basic security practices for routers, switches, servers, wireless networks, and connected devices.
Learn how to control and filter network traffic using Access Control Lists. Understand standard and extended ACLs, traffic filtering, wildcard masks, access rules, placement strategies, and Cisco ACL configuration and verification techniques.
Secure Cisco network devices using practical administrative controls. Learn SSH-based management, password protection, privilege levels, secure remote access, device hardening, login controls, and configuration practices that help protect enterprise networking infrastructure.
Learn how network administrators monitor infrastructure performance and availability. Understand device status, interface health, bandwidth usage, connectivity monitoring, network utilization, and identifying abnormal network behavior.
Understand network logging and Simple Network Management Protocol (SNMP) concepts used for device monitoring and management. Learn logs, alerts, monitoring data, SNMP basics, management information, and how administrators use monitoring information to maintain network reliability.
Learn how to analyze network performance and identify potential bottlenecks. Monitor latency, packet loss, bandwidth utilization, interface errors, and connectivity problems, and apply practical troubleshooting techniques to improve network performance and availability.
Develop practical skills for identifying security and connectivity issues. Learn to analyze logs, verify device configurations, troubleshoot ACLs, investigate suspicious network behavior, isolate faults, and apply structured security and troubleshooting procedures.
